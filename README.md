# Factorial Calculator 🚀

A simple Python program that calculates the factorial of a number using a function and loop.

---

## 📌 What is Factorial?
Factorial of a number n is:

n! = n × (n-1) × (n-2) × ... × 1

Example:
5! = 5 × 4 × 3 × 2 × 1 = 120

---
## ⚙️ How It Works
1. User enters a number
2. Program uses a function `find_fact()`
3. Loop multiplies numbers from 1 to n
4. Result is returned and printed
